Medidas y consejos de impresión

Cada franja incluye letras y borde. Imprime al 100 % con el mismo papel. El margen lateral por defecto es 0,62 cm (6,2 mm); puedes reducirlo a 0 para aprovechar todo el ancho. Oficio tiene variantes regionales; verifica las dimensiones. Los tamaños personalizados van de 20 a 2000 mm por lado. La impresora debe admitir el formato.

Cómo se calcula el sticker

La altura se calibra con una referencia fija: añadir palabras no cambia la escala. El borde blanco se une en una silueta continua, sin cortes internos. La separación entre palabras admite valores negativos (hasta -10 cm) para compactar o solapar palabras consecutivas. Al desactivar la limpieza se respetan espacios y líneas vacías; una tabulación equivale a cuatro espacios. El borde conserva una holgura mínima de seguridad.

Fuentes finas y detalles pequeños pueden perderse al imprimir. Las demos personales no autorizan uso comercial. No se exportan curvas de texto para plotter.
